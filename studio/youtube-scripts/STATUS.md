## House style used in this batch (for reconciliation with W1)

- Header table: Format / Teacher on camera / Runtime target / Spoken budget / Book basis / Mark in focus (W4 onward) / Primary text / Supporting texts / Spine / Status.
- Spine headings: `## OPEN`, `## CLAIM`, `## TEXT`, `## MOVEMENTS` (four `### Movement N` sections), `## APPLICATION` (`### Name it`, `### Do this week`, `### Tell a brother`, `### Carry this`), `## CLOSE`.
- Four marks sentence spoken verbatim exactly twice: once in OPEN, once in CLOSE. Individual marks referenced by phrase elsewhere.
- Claim stated twice, word for word, in CLAIM.
- "Do this week" always three concrete actions; "Tell a brother" always one named conversation with a scripted line; "Carry this" always one memorizable sentence said twice.
- Sign-off every week: "Stand firm. Act like men. Be strong. I'll see you next week." (1 Corinthians 16:13)
- Spoken CTA in CLOSE only: "subscribe and hit the bell."
- Stage directions in [brackets]: cold open, lower thirds, on-screen verse cards, [Beat.], [Slow down.], end card.
- No em dashes or en dashes anywhere in the file, including the description stub.
- File ends with `## DESCRIPTION + PINNED` containing `### YouTube description`, `### Pinned comment`, and `### CROSS-LINKS`.
